# 财务报表分析 SOP

评估一家公司的财务基本面，按"三张表"系统展开，既看当期水平也看趋势（同比/环比），避免只报单一数字。规划子问题时尽量覆盖下列检查项，每项都应带上大写股票代码（ticker）。

## 分析清单（检查项）

### 利润表（盈利能力与成长性）
1. **营收及增速**：营业收入规模与同比增速，判断成长性。
2. **毛利率**：反映产品/服务定价权，看趋势是否稳定或走弱。
3. **净利率**：整体盈利效率。
4. **净利润及增速**：与营收增速对比，判断是增收又增利还是增收不增利。

### 资产负债表（财务健康）
5. **资产负债率**：整体杠杆水平。
6. **流动比率 / 速动比率**：短期偿债能力。
7. **商誉占比**：高商誉隐含未来减值风险（可触发 risk_scan SOP）。

### 现金流量表（盈利质量）
8. **经营性现金流**：与净利润匹配度——利润高但经营现金流长期为负是危险信号。
9. **自由现金流**：经营现金流减去资本开支，反映真实造血能力。

### 回报率
10. **ROE / ROA**：股东与资产回报效率，ROE 可做杜邦拆解（净利率 × 周转率 × 杠杆）。

## 规划提示

- 实时基本面数值（营收、净利润、毛利率、ROE、负债率等）→ 用 finance_query，子问题写成 "TICKER fundamentals / financials" 形式。
- 财报原文细节、管理层讨论、附注 → 用 rag_search 检索 filings。
- 至少产出覆盖"盈利能力（营收/利润/毛利率）"与"财务健康（负债率/现金流）"两类的子问题。

## 输出结构建议

按盈利能力 → 财务健康 → 盈利质量三段组织，先给整体判断，再逐项用数据支撑，并点出趋势方向（改善/恶化）。
