# 行业对比分析 SOP

回答"这家公司在行业里处于什么位置 / 和同行比怎么样"，核心是选对可比公司，并用统一口径的指标横向对比，而不是孤立地看单家数据。规划子问题时尽量覆盖下列检查项，涉及个股数据时带上大写股票代码（ticker）。

## 分析清单（检查项）

1. **选取可比公司**：挑选 2–3 家同行业、体量相近的对标公司作为对比基准。
2. **估值横向对比**：各家的 P/E、P/S、EV/EBITDA 对比，判断目标公司在同行中偏贵还是偏便宜（与 valuation SOP 呼应）。
3. **盈利能力对比**：毛利率、净利率、ROE 横向对比，看目标公司盈利质量在同行中的位置。
4. **成长性对比**：营收增速、净利润增速对比，判断谁在抢份额、谁在掉队。
5. **市场份额 / 行业地位**：目标公司的市占率与排名，是龙头、追赶者还是边缘玩家。
6. **护城河对比**：品牌、成本、网络效应、切换成本等竞争壁垒的相对强弱。

## 规划提示

- 每家可比公司的实时估值与盈利数据 → 用 finance_query，对目标公司和对标公司分别写成 "TICKER fundamentals / P/E" 形式的子问题。
- 市场份额、行业格局、竞争壁垒 → 用 rag_search 或 web_search 补充。
- 至少产出覆盖"同行估值对比"与"同行盈利能力/份额对比"两类的子问题，且要出现目标公司之外的至少一个对标对象。

## 输出结构建议

先给目标公司在行业中的整体定位结论，再用一张"目标 vs 同行"的指标对照逐项支撑，最后点明相对优势与劣势。
