# 风险扫描 SOP

系统性排查一只股票的潜在风险，不能只凭单条负面新闻下结论，要从财务、经营、行业政策、估值四个维度交叉扫描。规划子问题时尽量覆盖下列检查项，涉及个股数据时带上大写股票代码（ticker）。

## 分析清单（检查项）

### 财务风险
1. **债务风险**：资产负债率、有息负债、短期偿债压力（流动比率）。
2. **现金流风险**：经营性现金流是否持续为负，是否依赖外部融资续命。
3. **商誉 / 减值风险**：高商誉占比隐含未来减值一次性冲击利润。

### 经营风险
4. **客户 / 供应商集中度**：大客户或单一供应商依赖导致的脆弱性。
5. **盈利可持续性**：利润是否依赖一次性收益、补贴或激进的收入确认。

### 行业 / 政策 / 监管风险
6. **政策与监管**：行业是否面临监管收紧、反垄断、合规处罚。
7. **诉讼与治理**：重大诉讼、退市预警、审计意见、大股东减持/质押。

### 估值风险
8. **估值过高的回调风险**：当前估值是否已透支预期（与 valuation SOP 呼应）。

## 规划提示

- 财务风险指标（负债率、现金流、商誉）→ 用 finance_query，子问题写成 "TICKER fundamentals / debt / cash flow" 形式。
- 财报风险因素章节（10-K risk factors）、诉讼/监管/退市/减值等事件 → 用 rag_search 检索 filings/news，或用 web_search 查最新负面信息。
- 至少产出覆盖"财务风险（债务/现金流/商誉）"与"经营或政策风险"两类的子问题。

## 输出结构建议

按风险维度分条列出，每条给出"风险点 + 依据 + 严重程度（高/中/低）"，最后汇总最需要警惕的 1–2 个核心风险。
