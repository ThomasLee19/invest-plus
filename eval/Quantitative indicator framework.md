# 量化指标框架（最终确认版）

## 测试对象

本机运行的真实前后端（backend :8000 + frontend :5181），走真实 agent/RAG/数据库/ES 逻辑，不是 mock。

## 四类指标

### 1. RAG 检索准确率

- **方法**：从 `data/` 语料（AAPL/MSFT/GOOGL 各一份 10-K/10-Q/8-K + 新闻 + 8 篇教育文档）里挑 15-20 道有明确答案的问题
- **标准答案** = 语料里实际写的内容（不代表真实世界，语料本身是合成测试数据，见下方"诚实声明"）
- **判定**：agent 回答里的关键数字/事实是否与语料一致 → 算出正确率
- **简历表述示例**："RAG 检索准确率 XX%（N 道人工核对问答题）"

### 2. Agent 工具路由准确率

- **方法**：准备 20-30 道覆盖不同意图的问题（finance_query 类、rag_search 类、web_search 类、无需工具类、复合意图类）
- **判定**：agent 实际调用的工具 vs 预期工具是否一致 → 算准确率
- **简历表述示例**："多工具路由准确率 XX%"

### 3. 响应延迟

- **方法**：真实调用 `/chat`，记录首字延迟（time-to-first-token）和完整回答延迟
- **输出**：均值 + 分布（如 p50/p90）
- **简历表述示例**："平均首字延迟 X.Xs，平均完整响应 X.Xs"

### 4. 边界输入鲁棒性

- **方法**：无效股票代码、空输入、超长输入、无关问题等场景
- **判定**：是否优雅处理（不崩溃、给出恰当提示）→ 通过率
- **简历表述示例**："边界场景优雅处理率 100%（N/N）"

## 诚实声明（用于 README，不上简历细节）

语料为项目自带的合成测试数据（内容可能由 AI 生成、日期为未来虚构日期），RAG 准确率衡量的是"回答对语料的忠实度"，不代表对真实世界财务数据的验证。
